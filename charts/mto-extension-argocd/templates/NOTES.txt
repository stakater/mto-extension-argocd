READ BEFORE UNINSTALLING
========================

Do NOT run `helm uninstall` on its own. It deletes the RBAC and the
TemplateInstances in one shot; the RBAC has no finalizers so it disappears
immediately, while each TemplateInstance lingers on its own finalizer -- and
that finalizer needs the RBAC that is already gone in order to delete the
AppProjects it owns. Nothing completes, and you are left hand-clearing
finalizers on every object.

Uninstall in this order instead:

  # 1. drop the parent; its children and their AppProjects drain while the
  #    RBAC still exists
  kubectl delete templateinstance.templates.v2.stakater.com \
    mto-argocd-parent -n {{ .Values.operatorNamespace }}

  # 2. wait until no children remain
  kubectl get templateinstance.templates.v2.stakater.com \
    -n {{ .Values.operatorNamespace }} | grep mto-argocd

  # 3. now the release can go
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}

Note what step 1 does to the AppProjects this release manages. On
template-operator-v2 8a44194 and later they are RELEASED and survive; on v0.0.6
and earlier they are DELETED, because retain is not enforceable there. See
docs/upstream-issues.md, TOV2-1.

If you are reinstalling, wait for `Template/mto-argocd-parent` to disappear
before doing so. `helm uninstall` returns before template-operator-v2 releases
its finalizer, and an install in that window fails with an ownership-metadata
error.
